# 错题记忆实验室

一个可直接部署到 GitHub Pages 的静态教育心理学实验网站。网站比较主动回忆复习与被动阅读复习在延迟测试中的错误率和重复错误数，包含匿名在线实验、数据录入、原生图表、中文实验报告和导出功能。

## 本地预览

本项目不需要安装依赖。可直接打开 index.html，或在项目目录运行任意静态文件服务器：

    python -m http.server 8080

然后访问 http://localhost:8080。

## 正式实验注意事项

- 页面中的初始数据和报告默认标记为“演示数据”，不能作为真实课程结论。
- 正式模式会在当前浏览器记录匿名编号、时间、分组、阶段状态和答题结果。
- 静态网站不能提供可靠的跨设备、跨用户云端汇总。正式数据应通过 JSON/CSV 导出，再由研究者人工去重、汇总和分析。
- 一周延迟测试应真实等待。不要让参与者使用即时演示模式代替长期记忆实验。
- 招募参与者前，请确认课程教师和所在学校的伦理、知情同意与数据管理要求。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库，把 index.html、styles.css、app.js 和 README.md 上传到仓库根目录。
2. 打开仓库的 Settings，进入 Pages。
3. 在 Build and deployment 中选择 Deploy from a branch。
4. 选择 main 分支和 /(root) 目录并保存。
5. 等待 GitHub 生成公开地址。

网站没有构建步骤，也没有外部运行时依赖。
